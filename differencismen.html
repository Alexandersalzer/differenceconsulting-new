DIFFERENCISMEN

Ett system för självledarskap i prestation.

Differencismen utgår från människan bakom prestationen.

En filosofi för hur människan möter sig själv, verkligheten och det som sker.

Ett system som gör det inre arbetet konkret, träningsbart och synligt.

Träningsfältet är där förståelsen möter verkligheten – där självledarskapet tränas genom det som sker och blir synligt i beteendet över tid.

MÄNNISKAN

Människan är större än prestationen.

  • Prestationen spelar roll.
  • Resultatet spelar roll.
  • Rollen spelar roll.

Människan är fortfarande större än det senaste utfallet.

Människan och prestationen hör ihop utan att vara samma sak.

En prestation kan vara otillräcklig utan att människan blir otillräcklig.

Ett beteende kan behöva utvecklas utan att människan reduceras till beteendet.

Ett resultat kan få konsekvenser utan att ensamt avgöra hela sanningen om människan eller arbetet.

  • Människan är större än prestationen.
  • Människan bär fortfarande ansvar för hur prestationen byggs och möts.

SJÄLVLEDARSKAPET

Allt går inte att styra.

Hur du leder dig själv genom det som sker går att träna.

Självledarskap innebär inte full kontroll över tankar, känslor, resultat eller omständigheter.

Det handlar om att utveckla ett större handlingsutrymme mellan det som sker och nästa handling.

  • Känslan kan uppstå.
  • Reaktionen kan aktiveras.
  • Resultatet kan göra ont.
  • Rollen kan förändras.

Riktningen behöver fortfarande kunna återtas.

Självledarskap handlar inte om att aldrig tappa riktningen.

Det handlar om att:

  • upptäcka tidigare,
  • förstå tydligare,
  • välja mer medvetet
  • och återgå snabbare.
  • Självvarande.
  • Dåvarande.
  • Härvarande.
  • Framvarande.

Tillståndet färgar hur människan möter sig själv och det som sker.
